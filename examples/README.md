# Examples

This directory contains documentation examples for the Apollo provider scaffold.

The examples are intentionally schematic. The provider surface is scaffolded, but the GraphOS Platform API integration is not implemented yet.

- `provider/provider.tf` is used for the provider index page.
- `data-sources/<full data source name>/data-source.tf` is used for data source pages.
- `resources/<full resource name>/resource.tf` is used for resource pages.
